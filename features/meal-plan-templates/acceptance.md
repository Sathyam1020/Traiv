# Acceptance

- Create populates requested recipe alternatives for enabled meals when eligible recipes exist.
- Allergen/source constraints never silently relax; shortages and locked conflicts are visible.
- Macro and enabled meal percentages total 100; disabled meals are 0.
- Reopen, edit, save, publish, discard, duplicate and archive preserve ownership/versioning.
- Settings use the same prefilled sheet in Create/Edit; save controls require changes.
- Plan-specific quantities and locks persist; original library recipes remain unchanged.
- Publish returns to list, showing Live; saved Live edits show Local changes.
- Founder will perform UI acceptance. No automated/browser checks run per instruction.
