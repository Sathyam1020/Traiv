# Acceptance criteria (founder UI review pending)

- Client Nutrition tab has the supplied empty/create/copy flows.
- Client plans never appear in the studio Mealplans list.
- Published templates copy independently with fresh child IDs and optional targets.
- Draft plans and edits remain invisible to the client until published.
- Trainer edits use the same settings/builder/recipe sheet as Phase C.
- Read-only Food view uses published snapshots and client authorization.
- Client plan switching, errors, repeat-safe creation and stale save protections exist.
