# Client nutrition assignment

Client Nutrition offers Create new plan and Create from template. New plan reuses the
settings sheet with the client name and a recommendation Apply control. A client plan
has clientId and stays outside Mealplans. Template picker lists only published studio
templates, then offers name and existing/custom calorie/macro configuration. Copying
uses published source content, not unpublished changes.

Created plans remain Draft until Publish. Client tab embeds PlanBuilder and meal recipe
sheet, with selection among multiple client plans and archive. Saved edits to a Live
plan show Local changes without changing the client's published content. Food reveals
only once a published plan exists and lets clients read ingredients and steps. No food
logging in this phase.
