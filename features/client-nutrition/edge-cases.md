# Edge cases

Client belongs to another studio or was removed; source is a client plan, unpublished
or archived; published template has newer private edits; empty eligible library; lost
creation response; concurrent publish/save/archive; old browser draft; custom targets
with locked recipes; no calorie suggestion before intake; multiple published client plans.

Source/ownership validation and snapshots preserve boundaries. Existing shortage and
publish validation applies. Archived plans disappear from trainer and client lists.
