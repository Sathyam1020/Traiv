# Phase 7b distribution

## Launch sequence

1. After deploying, confirm the public sitemap contains all 110 tool URLs and rerun the route audit against production.
2. Submit https://www.traiv.fit/sitemap.xml in the verified [Google Search Console property](https://search.google.com/search-console) and [Bing Webmaster Tools property](https://www.bing.com/webmasters/). Record submission date, status, and detected URLs. Check the [Google sitemap guide](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) and [Bing sitemap guide](https://www.bing.com/webmasters/help/Sitemaps-3b5cf6ed).
3. Coordinate IndexNow with Phase 8. Publish the verification key and submit changed canonical URLs after successful deployment. Check responses and the IndexNow report in Bing. [Bing URL submission](https://www.bing.com/webmasters/help/URL-Submission-62f2860b)
4. Inspect indexing on the initial promoted pages. Review weekly for the first month by landing page and query. Record impressions, clicks, CTR and position alongside tool CTA clicks. Confirm signup attribution before using it to compare conversion rates.
